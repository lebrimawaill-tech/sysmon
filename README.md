# sysmon

The complete source project is in [`project/`](project/). It contains the
kernel module, command-line collector, tests, and build files.

Clone the repository and enter the project folder:

```sh
git clone https://github.com/lebrimawaill-tech/sysmon.git
cd sysmon
cd project
```

Follow [the compilation and usage guide](project/README.md) to install
dependencies, build, run, and test sysmon. Run its build and collector
commands from `project/`; logging creates `project/sysmon.log` if it is missing.
